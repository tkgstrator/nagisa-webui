適用中フィルタのチップ filter-chips

サイドバーのフィルタパネルと対になる表示。パネル側でも選択状態は分かるので、ここは「いま何件に絞られたか」を伝えるのが主目的。種別ラベルは書かず、配信元だけブランド色の淡い下地で他と区別する。追加時は小さく弾んで入る。

角丸 999px の丸いチップ 配信元はブランド色の下地 種別ラベルは省略
