エラー表示 error-state

例外を受け取ったときに本文と差し替える画面。利用者が次に何をすればいいかを先に示し、開発者向けの生のエラー文は「技術的な詳細」を開いたときだけ見せる。NotFound (404) も同じ枠で扱う。

fable 案 = 左寄せ・情報密度高め左端 3px のアクセントで深刻度を示す要求と結果は罫線だけの表で並べる生のエラー文は 技術的な詳細 の中だけ囲み枠と影は使わない

500 · サーバー内部エラー

500 INTERNAL SERVER ERROR

データの取得に失敗しました

サーバー側で予期しないエラーが発生しました。データは失われていません。しばらく待ってから再読み込みしてください。

リクエストGET /anime/{id}
ステータス500 Internal Server Error
発生時刻2026-09-18 13:04:22
ホームに戻る
技術的な詳細 
Zodios: request failed with status 500 Internal Server Error on get /anime/9e7134ef-299a-5e74-b7fa-75c162a8fcbb

API が 5xx を返した。利用者側では解決できないので、再読み込みだけを促す。

503 · 一時的に利用できない

503 SERVICE UNAVAILABLE

一時的に利用できません

メンテナンス中か、アクセスが集中しています。時間をおいてから再度お試しください。

リクエストGET /anime
ステータス503 Service Unavailable
発生時刻2026-09-18 13:07:51
ホームに戻る
技術的な詳細 
Zodios: request failed with status 503 Service Unavailable on get /anime

メンテナンスや過負荷。時間をおけば直る見込みがあることを伝える。

— · ネットワーク到達不能

NETWORK ERROR

サーバーに接続できません

ネットワークに接続されていないか、サーバーに到達できませんでした。接続を確認してから再度お試しください。

リクエストGET /anime/{id}
ステータス応答なし
発生時刻2026-09-18 13:09:03
ホームに戻る
技術的な詳細 
TypeError: Failed to fetch

ステータスコードが無い。表のステータス行も「応答なし」に変わる。

404 · ルート不在

404 NOT FOUND

ページが見つかりません

お探しのページは存在しないか、移動した可能性があります。

パス/anime/2026/autumn
ホームに戻る アニメ一覧へ

存在しない URL。API を叩いていないのでメタ情報はパスだけ。

404 NOT FOUND

この作品は見つかりませんでした

指定された ID に一致する作品がデータベースにありません。削除されたか、URL が間違っている可能性があります。

リクエストGET /anime/{id}

発生時刻2026-09-18 13:04:22

考えられる原因

  • 作品が削除され、参照だけが残っている
  • 古いブックマークや共有リンクから開いた
  • URL の ID を手で書き換えた
