ページネーション pagination

astra 案はページ番号を並べず、前/次の丸ボタンと中央の位置表示だけに絞る。ポスターグリッドの下で視線を奪わないことを優先し、ページ番号への直接ジャンプは捨てている。長いリストでは「続きを読み込む」に置き換える。

ページ番号への直接ジャンプは持たない 中央寄せ / 幅は内容なり 数値は tabular-nums
