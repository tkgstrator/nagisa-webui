サーバーステータス server-status

サイドバー最下段から開く録画サーバー (nagisa) の状態ダイアログ。「いま動いているか」「何を待っているか」「取りこぼしていないか」の 3 つだけを載せ、Redis・CPU・メモリ・ディスク・台帳といった数値は詳細ページ /admin/status に送る。載せる項目は fable 案と同じで、中央寄せの言い切りとやわらかい面で組むところだけが違う。

astra 案 = 中央寄せ・言い切り・要点だけアイコンは 56px の円章囲み枠は引かずやわらかい面で分けるダイアログ幅 512px (sm:max-w-lg)最下段の導線は状態によらず同じ位置
